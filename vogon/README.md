# Vogon – Self-Hosted AI Form Filler

On-premise LLM that turns a short request into a filled travel request / purchase order and a draft email, with human approval.

## Scope
- Self-hosted inference (Ollama / vLLM), no external API calls
- Chat interface
- RAG over THWS forms, templates, policies
- Form filling (PDF) and email drafting
- Reference: SPARK Workflow (EUPL 1.2): keep license notices on adapted code
