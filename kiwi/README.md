# KIWi – KI-Wissensassistenz for the THWS CampusPortal

Locally hosted RAG assistant answering HISinOne questions with source citations.

## Scope
- Local LLM deployment (Ollama / vLLM), no external API calls
- Knowledge ingestion pipeline into a vector store
- RAG pipeline with source references
- Chat interface
- Evaluation: accuracy, relevance, hallucination rate
