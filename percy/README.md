# Percy – Agentic Inbox Butler for Microsoft 365

Redirect mail to an agent that triages and summarises the inbox on a schedule and pings your phone (Telegram/WhatsApp) when something is urgent.

## Scope
- Microsoft Graph API (OAuth2) / Outlook redirect ingestion
- LLM triage: urgent / action-needed / FYI / noise
- Scheduled digests
- Real-time urgent alerts
- User config: cadence, urgency rules, channel, quiet hours
- Data handling: inference location and storage minimisation
